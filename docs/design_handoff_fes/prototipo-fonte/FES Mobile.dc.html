FES · App mobile (PWA)

Layout de aplicativo instalado: barra de navegação inferior, telas em tela cheia, painéis que sobem da base e aviso de instalação. Entre pelo login e navegue pela barra inferior. Cada aparelho simula um perfil.

Layouts: Web PWA Web responsive
InstalávelAbre em tela cheia, com ícone FES na tela inicial e atalhos para Ações e Rotina 1:1.
iPhone · SafariAbra o link do FES, toque em Compartilhar e depois em Adicionar à Tela de Início.
Android · ChromeO app oferece o botão Instalar no próprio aviso. Funciona offline com os dados já carregados.
